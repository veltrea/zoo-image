FileMaker Plug-in / macOS

画像を、止めずに
見せる。

FileMaker の外部関数は計算エンジンの上で同期実行されます。そこで重い画像を描けば、 画面はそのあいだ固まります。ZooImage は描画を専用のビューアアプリに預ける薄いプラグインです。 コンテナでもファイルパスでも、関数ひとつで独立したウィンドウに開きます。

  FileMaker スクリプト
# コンテナフィールドの画像を、ズーム合わせで開く
Set Variable [ $v ; zim_Show ( Photos::Image ; "{\"theme\":\"rich\",\"zoom\":\"fit\"}" ) ]

# 開いたあとも FileMaker 側から操作できる
Set Variable [ $_ ; zim_SetZoom ( "main" ; 2 ) ]
Set Variable [ $_ ; zim_Navigate ( "main" ; "next" ) ]
01 — 特長

ビューアは別プロセス。
だから固まらない。

プラグイン本体は薄い IPC クライアントに徹しています。表示・ズーム・スクロールはすべて同梱のビューアアプリ側で動くため、FileMaker の操作感はそのままです。

どちらでも開ける

コンテナフィールドの値でも、ディスク上のファイルパスでも、同じ zim_Show で開きます。コンテナは自動で一時ファイルに書き出されます。

思い通りに拡大

数値指定のほか fit / fill / actual / in / out。ホイールでのズーム、ドラッグでのパンにも対応します。

連続して見る

パスの配列を渡せば、← → キーとフィルムストリップで送れます。スクリプトからも zim_Navigate で移動できます。

操作を受け取る

閲覧・ズーム・移動・クリック・ドロップといった操作を、FileMaker スクリプトの引数として受け取れます。

複数を並べる

ビューアは名前で識別します。before と after のように、任意の数のウィンドウを同時に扱えます。

単体でも動く

同梱のビューアは普通の画像ビューアとしても使えます。ドラッグ＆ドロップ、File ▸ Open、キーボード操作に対応。

撮影情報を読む

カメラ・レンズ・絞り・ISO・撮影日時・GPS を JSON で取得できます（zim_ExifRead）。ビューアを起動せずに動くので FileMaker Server でも使えます。読み取り専用です。

02 — 関数

覚えることは、17 個だけ。

すべて zim_ で始まります。成功すれば値を、失敗すれば ERROR: で始まる文字列を返します。

関数はたらき
zim_Showコンテナまたはパスをビューアで開く
zim_Closeビューアを閉じる（"*" ですべて）
zim_SetZoom倍率、または fit / fill / actual / in / out
zim_SetWindow位置とサイズ。空の引数は据え置き
zim_SetThemerich（情報パネル付き）／ minimal（枠なし）
zim_SetTitleウィンドウタイトルを変える
zim_Focusウィンドウを最前面に出す
zim_SetFullscreen全画面の切り替え
zim_LoadListプレイリストを読み込む
zim_Navigatenext / prev / first / last / 番号
zim_GetState現在の状態を JSON で取得
zim_SetScriptイベントで起動するスクリプトを登録
zim_ExifReadコンテナ画像の EXIF を JSON で読む
zim_ExifReadPathファイルの EXIF を JSON で読む
zim_Versionバージョン。読み込み確認にも使える
zim_IsRunningビューアが起動しているか
zim_LastError直近のエラーメッセージ
引数と戻り値の詳しい仕様は 関数リファレンスに、 コピーして使えるスクリプト例は サンプル集にあります。
03 — 導入

入れて、再起動するだけ。

管理者権限は要りません。配布ファイルはコード署名済みです。

ダウンロードする

リリースページから ZooImage-0.1.0-macOS.zip を取得して展開します。コンテナ経由で配りたい場合は .fmplugin.gz の方を使います。

Extensions に置く

~/Library/Application Support/FileMaker/Extensions/ に ZooImage.fmplugin を入れます。スクリプトから配る場合は「プラグインファイルをインストール」ステップが使えます。

FileMaker を再起動する

プラグインは起動時に読み込まれます。zim_Version が値を返せば成功です。

初回だけ確認が出ることがあります。 Apple の有料開発者登録を使わず、ad-hoc 署名で配布しているためです。 その場合は Finder で右クリック →「開く」を選ぶか、システム設定のプライバシーとセキュリティから許可してください。 配布ファイルの署名は、公開前に実機で検証しています。
